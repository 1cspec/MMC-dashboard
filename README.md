# Дашборд проекта ММЦ

Одностраничный статичный дашборд для статус-встреч: активности проекта (номер · задача · ответственный · статус с краткой динамикой и следующим шагом), общий прогресс, вехи плана, риски.

> Содержимое этого репозитория формируется автоматически из рабочего репозитория проекта — правки вносятся там, здесь они только публикуются.

## Состав

```
├── index.html            # весь дашборд (HTML + CSS + JS, без сборки)
├── .nojekyll             # отключает Jekyll на GitHub Pages (важно для папки «данные»)
└── данные/
    ├── статус.json       # здоровье, прогресс, резюме блоками, метрики, риски, контакты
    ├── план_проекта.json # этапы и вехи (Roadmap)
    └── задачи.json       # таблица активностей: группы → строки (id, task, owner, status, statusText, note)
```

Статусы активностей в `задачи.json`: `done` — выполнено · `green` — идёт по плану · `yellow` — требует внимания / ждёт заказчика · `red` — заблокировано · `gray` — не начата. Поле `statusText` — подпись на плашке, `note` — динамика и следующий шаг.

Здоровье проекта в `статус.json` (`health`): `GREEN` — стабилен · `YELLOW` или `AMBER` — требует внимания · `RED` — критическое.

**Состояние проекта задаётся блоками.** Поле `summaryPoints` — массив `{title, text, accent}`, где `accent` необязателен и принимает значения `accent-ok` (зелёная отметка), `accent-warn` (оранжевая), `accent-danger` (красная); без него отметка синяя. Блоки выводятся сеткой, поэтому каждый абзац читается отдельно. Поле `summary` (сплошной текст) сохранено как запасной вариант: оно используется, только если `summaryPoints` не задано.

## Как устроена вёрстка

Все длинные тексты — динамика активностей, описания вех, меры по рискам — выводятся **на всю ширину страницы**, а не в узкой колонке: именно из-за узких колонок дашборд был нечитаем. Активности выводятся карточками (заголовок строкой, текст под ним), вехи и риски — сетками `auto-fit`, которые сами схлопываются в одну колонку на узком экране. Проверять правки удобно локальным сервером (см. ниже) на ширинах 1680 / 1280 / 768.

## Локальный просмотр

Открытие `index.html` напрямую из файла показывает демо-данные: браузер блокирует чтение локальных JSON (CORS), появляется предупреждающий баннер. Чтобы увидеть реальные данные, поднимите локальный сервер в этой папке:

```bash
python -m http.server 8777
```

Затем откройте http://127.0.0.1:8777/index.html

## Зависимости

Внешних сборок нет. Страница подключает по CDN: шрифты Google Fonts (Inter, Outfit) и Chart.js для диаграмм.

Недоступность CDN не ломает дашборд: построение диаграмм обёрнуто в отдельную защиту, панель «Аналитика» просто скрывается, а данные отображаются полностью. Раньше одна недоступная библиотека уводила всю страницу в демо-режим.
